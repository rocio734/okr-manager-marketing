La arquitectura

Cómo la IA hace el trabajo

1. GitHub Actions corre el script cada viernes a las 5pm
→ Python lee datos reales del CRM + Search Console + Etendo

2. El script arma el contexto y llama a la API de Claude
→ Claude analiza, razona y devuelve JSON con propuestas

3. Las propuestas se guardan en Supabase con justificación
→ El dashboard web muestra las propuestas para aprobar

4. Al aprobar, Playwright abre Etendo y escribe los valores
→ KRs actualizados con historial y comentario automático
